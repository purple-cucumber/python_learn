# 酒店评论情感聚类分析

本代码基于酒店评论的情感特征和旅客类型标签，使用 KMeans 聚类发现酒店群体模式。

## 步骤概览
1. 加载已处理的酒店评论数据（包含情感得分和标签列）
2. 按酒店聚合特征（如平均情感得分、平均评分、旅客类型比例等）
3. 标准化特征以消除量纲差异
4. 使用肘部法选择最佳聚类数 K
5. 训练 KMeans 模型并分配簇标签
6. 查看每个簇的统计特征，解释簇含义

## 完整代码

```python
import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
import matplotlib.pyplot as plt

# 1. 加载数据（请根据实际路径修改）
df = pd.read_csv('D:/deeplearning_study/ML-For-Beginners/6-NLP/data/Hotel_Reviews_NLP.csv')

# 2. 按酒店聚合特征：将评论级数据转换为酒店级数据
hotel_features = df.groupby('Hotel_Name').agg({
    'Positive_Sentiment': 'mean',          # 平均正面情感得分
    'Negative_Sentiment': 'mean',          # 平均负面情感得分
    'Reviewer_Score': 'mean',              # 平均评论者评分
    'Total_Number_of_Reviews': 'first',    # 酒店总评论数（组内常量，取第一个）
    'Leisure_trip': 'mean',                # 休闲旅行评论比例
    'Couple': 'mean',                      # 情侣评论比例
    'Solo_traveler': 'mean',               # 独自旅行评论比例
    'Business_trip': 'mean',               # 商务旅行评论比例
    'Group': 'mean',                       # 团体评论比例
    'Family_with_young_children': 'mean',  # 带小孩家庭评论比例
    'Family_with_older_children': 'mean',  # 带大孩家庭评论比例
    'With_a_pet': 'mean'                   # 带宠物评论比例
}).reset_index()

# 3. 处理缺失值（如有）
hotel_features = hotel_features.fillna(0)

# 4. 选择用于聚类的特征列
feature_cols = ['Positive_Sentiment', 'Negative_Sentiment', 'Reviewer_Score', 
                'Total_Number_of_Reviews', 'Leisure_trip', 'Couple', 
                'Solo_traveler', 'Business_trip', 'Group', 
                'Family_with_young_children', 'Family_with_older_children', 'With_a_pet']
X = hotel_features[feature_cols]

# 5. 标准化特征（均值为0，标准差为1），消除量纲差异
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 6. 肘部法确定 K 值：观察 inertia 随 K 的变化
inertia = []
for k in range(1, 11):
    kmeans = KMeans(n_clusters=k, random_state=42)
    kmeans.fit(X_scaled)               # 只需训练模型以获取 inertia
    inertia.append(kmeans.inertia_)    # inertia_ 是所有样本到其簇中心距离的平方和

plt.plot(range(1, 11), inertia, marker='o')
plt.xlabel('Number of clusters')
plt.ylabel('Inertia')
plt.title('Elbow Method')
plt.show()

# 根据肘部图选择 K（这里假设 K=3）
kmeans = KMeans(n_clusters=3, random_state=42)
# fit_predict 同时训练模型并返回每个样本的簇标签
hotel_features['Cluster'] = kmeans.fit_predict(X_scaled)

# 7. 查看每个簇的统计特征（各特征的平均值）
cluster_summary = hotel_features.groupby('Cluster')[feature_cols].mean()
print(cluster_summary)

# 可选：查看每个簇包含的酒店数量
print("\n每个簇的酒店数量：")
print(hotel_features['Cluster'].value_counts())
```
### 关键概念说明
- `groupby().agg()`：按酒店分组并计算多个统计量，将评论级数据转换为酒店级数据。

- `StandardScaler`：标准化特征，使不同量纲的特征具有可比性，避免 KMeans 被数值大的特征主导。

- `inertia_：KMeans` 模型的属性，表示所有样本到其所属簇中心的距离平方和，用于肘部法选择 K。

- `fit_predict`：训练模型并直接返回每个样本的簇标签，等价于先 fit 再 predict。

- `cluster_summary`：按簇分组计算各特征的平均值，帮助理解每个簇的特点（如“高评分酒店”、“商务型酒店”等）。

### 注意事项
确保数据文件路径正确，或修改为相对路径。

如果数据量很大，可以考虑使用 MiniBatchKMeans 提高效率。

肘部法的拐点需要人工判断，也可以使用轮廓系数等指标辅助选择 K。
